# Code of Conduct

Windows Printer Sharing Fix welcomes users and contributors with different levels of Windows, PowerShell, networking, and printer experience.

## Expected behavior

- Be respectful and specific when discussing bugs, security trade-offs, or implementation choices.
- Critique code and technical claims, not the person making them.
- Assume good intent, but verify risky technical claims with evidence.
- Help newcomers provide useful reproduction details instead of dismissing incomplete reports.
- Protect privacy: do not pressure users to publish credentials, internal hostnames, private addresses, or other sensitive data.
- Keep discussions relevant to Windows printing, the project, or its contribution process.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, deliberate misinformation, credential sharing, doxxing, spam, and attempts to pressure contributors into unsafe production testing are not acceptable.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates these expectations and may restrict participation when needed to keep the project safe and productive.

For conduct concerns that should not be handled publicly, contact the maintainer through the GitHub profile.
